Guides answer one task from start to finish, in your app: what to install, where each piece goes, what the user sees
after each step, and what breaks. Find the task you have below.

If you are new to the library, read [Quick start](../start/quick-start) and
[Starting the app](../fundamentals/starting-the-app) first: the guides build on `createNavigation`, `defineScreen` and
`navigation`.

thought here. Each guide below shows where its provider goes and what to watch.
