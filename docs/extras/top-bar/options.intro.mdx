## Set it {#set}

In the definition of the screen, from the screen while it shows, or for every screen of the app. The screen's own options go over the app defaults, and the options set while it shows go over both, key by key. More: [Screen options](/docs/fundamentals/screen-options#layers).

## Chain methods {#chain}

Short ways to set the most common keys in an options chain.

| Method | Sets |
| --- | --- |
| `s.title(text \| title)` | `topBar.title`; a string is its text. |
| `s.subtitle(text \| subtitle)` | `topBar.subtitle`; a string is its text. |
| `s.largeTitle(on = true)` | `topBar.largeTitle`; `true` shows it, an object sets it. |
| `s.hideTopBar(hidden = true)` | `topBar.visible`: `false` hides the bar. |
| `s.topBar(options)` | Any keys of `topBar`. |
